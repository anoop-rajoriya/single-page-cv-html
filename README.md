# Single-Page CV (HTML Only) - [Live Link](example.com)

A single page resume website, it relise entirely on HTML document no extenal CSS or JS files. It demonstrate how single page layout created using `<section>` tags and implement foundation SEO principles.

## What I Implement

- **Semantic Document Structure :** Organized the page layouts using `<header>`, `<main>`, `<section>`, `<article>`, and `<footer>` tags.
- **In-Page Navigation :** Added a jump `<a>` links to the main sections IDs.
- **List and Tabular Data :** Organized data using lists and tables tags among sections.
- **Text Formatting and Inline Semantics :** Added basic text formating using text formatting and inline semantics tags.
- **Page MetaData and SEO :** Configured standard meta tags - `title`, `description` and `viewport` alongside Open Graph (OG) protocols tags - `og:title`, `og:desc`, `og:type`, and `og:site_name`.
